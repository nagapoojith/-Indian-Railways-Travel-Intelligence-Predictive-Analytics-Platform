I built a comprehensive railway intelligence platform by using multiple railway datasets, real-time APIs, and interactive analytics.

The goal of this project was to transform railway data into meaningful insights that help users explore train schedules, analyze delays, track live train status, monitor weather conditions, understand crowd patterns, and make smarter travel decisions.

🗂️ Data Collection & Integration

Instead of relying on a single dataset, I collected and analyzed 10 different railway datasets from Kaggle and Data.gov.in.

The datasets covered:

▸ Historical Train Delay Data

▸ Train Schedules & Timetables

▸ Train Route Information

▸ Running Days & Frequency Data

▸ Station Information

▸ Arrival & Departure Timings

▸ Route Distance Data

▸ Fare & Class Details

▸ Train Operations Data

▸ Railway Network Information

The data was available in both CSV and JSON formats. After collecting the datasets, I performed data cleaning, preprocessing, transformation, and integration to create a unified railway intelligence platform.

🚅 Train Search & Route Discovery

📡 Live Train Status Tracking

🗺️ Interactive Route Visualization

⏳ Historical Delay Analysis
